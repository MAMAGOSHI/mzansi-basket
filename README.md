# 🛒 Mzansi Basket

**Shop smarter. Save more.**

🔗 **Live App:** https://mzansi-basket.onrender.com/

Mzansi Basket is a grocery price comparison web application designed to help South African shoppers compare grocery prices, analyse receipts and identify potential savings.

### Features

* 🔎 **Price Comparison:** Compare grocery prices across retailers using the Loyalty Hub API.
* 🧾 **Receipt Analysis:** Use Gemini AI to extract grocery items and prices from receipt images.
* 📊 **Data Visualisation:** View price comparisons and potential savings through charts.
* 💬 **Review Analysis:** Explore basic sentiment analysis of grocery reviews.
* 🛍️ **Grocery Insights:** Browse insights into common grocery categories and retailer positioning.

### Tech Stack

Python · Flask · HTML · CSS · JavaScript · Gemini API · Loyalty Hub API · Chart.js

### Deployment

Hosted on Render.

*Prices are indicative and depend on the data available from Loyalty Hub.*
